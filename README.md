# 🐱 喵喵助手 (MiaoAssistant)

一个安全、离线、保护隐私的 Android 无障碍输入小工具。在你输入标点符号（。！？；）时，自动将句子中的“我”替换为“本咪”，并在句末添加“喵”。

## ✨ 主要功能

- **自动加喵**：输入句号、问号、感叹号、分号时，自动在标点前插入“喵”。
- **人称替换**：自动将“我”替换为“本咪”（可在主界面关闭）。
- **完全离线**：不需要联网，所有文字处理都在手机本地进行。
- **保护隐私**：**没有申请任何网络权限**，不会上传任何聊天记录或数据。

## 💡 为什么要做这个项目？

市面上曾经有一款叫“QQ喵喵助手”的类似工具，但有人发现它会偷偷使用无障碍权限上传数据，甚至可能窃取聊天内容。这让我感到非常不安——**作为普通用户，我们不应该在“卖萌”和“隐私”之间做选择。**

于是，我这个“纯小白”决定自己动手写一个**干干净净的替代品**。  
这个项目的所有代码都经过反复检查，**不联网、无后门、不偷数据**，每一个功能都可以被任何人验证。

我希望用它证明：**哪怕是一个初学者，也能写出安全、透明、值得信赖的工具。**  
也希望能让更多朋友意识到：**隐私不是奢侈品，而是每个人应有的权利。**

## 📱 如何安装与使用

1. 下载本仓库中的 `main.zip` 源码包，或直接下载 APK 安装包（如果有的话）。
2. 将 APK 安装到手机上。
3. 打开 App，点击“开启服务”，跳转到系统无障碍设置。
4. 在无障碍列表中找到“喵喵助手”，打开开关。
5. 返回 App 确认状态显示“✅ 已开启”。
6. 打开 QQ、微信等聊天软件，输入文字并加上句号（。），就会自动变成“本咪”和“喵”啦！

## 🔒 隐私声明

本应用**完全不联网**，**没有任何后台偷偷运行的服务**。无障碍权限仅在本地处理文字替换，不会记录或上传任何数据。你可以放心使用。

## ⚠️ 注意事项

- 如果杀后台后服务停止，请重新去系统设置中打开无障碍开关。
- 本应用仅支持 Android 7.0（API 24）及以上版本。
